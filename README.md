# Elevmod – 한국형 엘리베이터 모드 (Minecraft 1.20.1 / Forge 47)

나무위키 「엘리베이터」, 「엘리베이터/구성」, 「엘리베이터/종류」 문서를 기준으로 만든, **실제로 움직이는 카**가 있는 엘리베이터 모드입니다.

jar 파일은 저장소의 **Releases** 에서 받을 수 있습니다 (GitHub Actions 가 push 할 때마다 빌드).

## 빠른 설치 순서

1. 승강로(빈 수직 공간)를 만들고, 각 층 승강장 쪽 벽에 **승강장 문**을 설치합니다. 문은 여러 칸을 이어 붙여 폭·높이를 만듭니다 (예: 1×2, 2×2, 자동차용 3×3).
2. 기계실(또는 아무 곳)에 **제어반**을 설치합니다.
3. **승강기 링커**로 제어반을 우클릭해 선택한 뒤, 각 층의 승강장 문을 우클릭하면 층이 등록되고 카가 나타납니다.
4. 승강장 **호출 버튼**, **층 표시기**, **홀랜턴**, **소방운전 스위치** 등도 링커로 우클릭해 연결합니다 (가장 가까운 층에 자동 배정).
5. 권상기·조속기를 링커로 연결하면 쉬브가 실제 속도로 회전하고 로프가 기계실까지 이어집니다.
6. 제어반을 맨손으로 우클릭하면 설정 화면(사양·기능·층 표기·운전/시험·정보)이 열립니다.
7. 카 안에서 **운전반**을 바라보고 우클릭(또는 웅크리고 맨손 우클릭)하면 운전반 화면이 열립니다.

> 카 정면은 처음 연결한 문의 방향입니다. 정반대 방향의 문을 연결하면 **관통형(앞뒤문)** 카가 됩니다.

## 아이템

- **승강기 링커**: 제어반 선택 → 문/장치/기계 연결. 웅크리고 우클릭 = 연결 해제, 다른 제어반에 웅크리고 우클릭 = 군관리 묶기, 허공에 웅크리고 우클릭 = 선택 해제
- **삼각키(도어키)**: 승강장 문 강제 개방(구출용). 카가 없는 층이면 운행이 즉시 정지됩니다.
- **소방 키**: 소방운전 스위치, 카 안 소방 1단/2단
- **운전원 키**: 카 안 독립운전/점검운전
- **승강기 점검기**: 제어반 진단, 웅크리고 우클릭 = 정기검사 합격 처리

## 다른 모드 연동 (월패드 등)

```java
// 세대 층(승강장 문 바닥 Y = floorY)으로 엘리베이터 호출
com.mchoe.elevmod.api.ElevatorAPI.call(serverLevel, controllerPos, floorY, false);
String floor = ElevatorAPI.currentFloor(level, controllerPos); // "1", "B2", "F" ...
int dir = ElevatorAPI.direction(level, controllerPos);         // 1 / -1 / 0
```
